AgentBouncr is paused.

AgentBouncr was a governance layer for autonomous AI agents: every tool call checked against a policy before it executed, with a tamper-evident audit trail behind it. Development has been paused, and the hosted service at this domain has been shut down.

This was a deliberate decision, not an outage. The project is being wound down in an orderly way rather than left to rot: the code, the data and the documentation have been archived, and this page will stay here.

If you installed an SDK

The published packages still install, but they have nothing to talk to — the API they default to is gone. Calls to agentbouncr.com will fail.

  • pip install agentbouncr — Python SDK, last release 0.2.0
  • npm install agentbouncr — TypeScript SDK, last release 0.1.2
  • n8n-nodes-agentbouncr — n8n community node, last release 0.1.1

They are marked as unmaintained. Nothing was unpublished: removing them would break anyone who still has them pinned, and would not undo the fact that they were released.

The code

The policy engine remains public and MIT-licensed. It is not maintained, but it is not going anywhere either.

  • github.com/agentbouncr/agentbouncr — the framework
  • github.com/agentbouncr/n8n-nodes-agentbouncr — the n8n node

If you had an account

The hosted service is shut down and its databases have been taken offline. If you had a workspace here and want to know what happened to your data, or want it deleted from the archived copies, write to hello@agentbouncr.com — that address still works.
